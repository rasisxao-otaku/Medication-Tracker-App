# くすりのこり

React + TypeScript で作った、オフライン利用向けのお薬残数カレンダーです。

## 起動方法

```bash
npm install
npm run dev
```

本番用ファイルの作成と確認:

```bash
npm run build
npm run preview
```

初回はオンライン環境でアプリを開いてください。PWAとしてアプリ本体を端末にキャッシュするため、次回以降はインターネット接続なしでも利用できます。ブラウザの「ホーム画面に追加」からインストールもできます。

## データと残数の計算

- お薬、1日の服用量、受診日はブラウザの `localStorage` に保存され、外部には送信されません。
- 残数は登録・更新した日の服用前の錠数を基準に、設定した毎日の服用量から日数分を差し引いて見積もります。
- 次回受診時に受け取る予定量を薬ごとに入力すると、受診日の服用前残数に加算した受診後残数と薬切れ予測を表示します。
- 実際に服用したかどうかは記録しないため、残数・薬切れ日は目安です。残数を更新すると、更新日を基準に再計算します。
- ブラウザのサイトデータを消去すると、保存したデータも消去されます。
